## 🧭 Creative Concept & Philosophy

This portfolio departs completely from conventional developer templates. It rejects standard hero banners, stock photographs, gradient blob graphics, and generic project grids in favor of an **intelligent, architectural personal operating system**.

### Design Synthesis:
- **Swiss Graphic Design**: Extreme typographic scale contrast, modular information grids, and disciplined spatial restraint.
- **Futuristic Operating Systems**: Subtle technical HUD telemetry, coordinate trackers, active node circuits, and monospace metadata.
- **A24 Film Title Sequence**: Cinematic blackout opening, letter-by-letter identity initialization, and film-style closing screen.
- **Apple Product Editorial**: High-fidelity typographic craftsmanship, tactile micro-interactions, and pure content clarity.

## 🚀 How to Run Locally

Because `port2` is built with **100% pure HTML, CSS, and minimal vanilla JavaScript**, it requires zero build steps or heavy dependencies.

### Option A: Open Directly in Browser
Simply double-click or open `port2/index.html` in any modern web browser.

### Option B: Serve with Local HTTP Server
Using Python:
```bash
cd port2
python -m http.server 8080
```
Then visit `http://localhost:8080/`.

Using Node / npx:
```bash
cd port2
npx serve .
```
