## 2. Deep Dive: Architectural Differences

### Portfolio 1 (Root Directory)
```text
Architecture: Modular Component-Driven (Vite)
src/
├── components/          # 12 separate JS modules (Hero, Disciplines, About, etc.)
├── data/
│   └── portfolioData.js # Centralized content object
└── styles/
    └── main.css         # Monolithic CSS design tokens and component classes
```
- **Strengths**:
  - Highly maintainable for quick content edits: changing a project title, CGPA, or bio only requires editing `portfolioData.js` without touching HTML or CSS.
  - Familiar component-oriented mental model similar to React/Vue, making it easy to migrate to a framework later if desired.
  - Accessible modal dialogs for project case studies.
- **Weaknesses**:
  - Follows a more conventional structure (Navbar at top, Hero, Cards, Footer) that looks similar to many high-end agency templates.
  - Requires Node.js and a build step to produce the production `dist/` bundle.

---

### Portfolio 2 (`port2/` Directory)
```text
Architecture: Zero-Dependency Pure Web Standards
port2/
├── index.html           # Semantic, deeply structured OS chapters (00 to 07)
├── style.css            # 2,200+ lines of bespoke Swiss graphic & HUD styles
└── main.js              # Physics-based ripple engine, orbital core state controller, telemetry monitor
```
- **Strengths**:
  - **Unforgettable First Impression**: Opening system initialization sequence (`SYSTEM / 001` typewriter reveal), followed by an austere, high-impact aesthetic.
  - **Zero Dependency & Future-Proof**: Will run 10, 20, or 50 years from now on any browser without npm vulnerabilities or broken build tools.
  - **Procedural CSS Artistry**: The orbital System Core is constructed entirely from CSS `border-radius`, concentric rings, keyframe orbits, and blend modes—showcasing mastery of low-level CSS layout and rendering.
  - **Fluid Water Ripple Interaction**: The 60fps canvas engine emits crystalline harmonic waves on mouse movement and click bursts, giving the dark void an alive, tactile atmosphere.
  - **Cognitive Topology Diagram**: Section `02 / SYSTEM` provides an interactive mind-map of how you break down problems, learn, build, teach, and lead.
- **Weaknesses**:
  - Text updates require editing `port2/index.html` directly rather than a standalone JSON file.
  - The bold aesthetic is experimental and unconventional (which is an intentional strength, but may surprise traditional corporate recruiters looking for standard resume layouts).
